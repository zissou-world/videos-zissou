# Vídeos Zissou

Projetos de vídeo feitos em código (three.js + canvas, renderizados com Chromium headless e ffmpeg).

| Pasta | Vídeo | Situação |
|---|---|---|
| `reuniao-mensal-2026-10/` | Reunião mensal de outubro/2026, com fotos do time (2m18s) | Projeto completo. Entregas finais em `entregas/`. |

## Histórico
- Antes deste repositório existir, foram feitos "Vendas é disciplina" (funil) e as duas primeiras versões de "A maior Black da nossa história" (57s e 80s), mais a primeira reunião mensal sem fotos.
- Os arquivos de projeto desses vídeos se perderam quando a sessão de trabalho foi encerrada. Ficaram só os vídeos entregues.
- A reunião mensal sem fotos está em `reuniao-mensal-2026-10/referencias/`. Os outros vídeos podem ser adicionados em `arquivo/` se alguém tiver as cópias.
- Cada projeto novo ganha a própria pasta, com o mesmo formato: `render/`, `assets/`, `scripts/`, `build.sh` e `README.md`.
